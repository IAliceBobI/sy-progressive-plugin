悬浮球是可放置在思源界面任意位置的快捷按钮：点击即可触发绑定的快捷键，或打开、关闭绑定的文档。在番茄工具箱设置的「悬浮球」板块开启，桌面端与移动端分别配置。

## 功能简介

思源里的高频操作大多依赖快捷键：开一张闪卡、在文档树中定位当前文档、翻阅昨天的 Daily Note，都是几下键盘的事。可一旦离开键盘，这些入口就都够不着了——移动端没有物理键盘，桌面上也总有双手离不开鼠标的时刻。另外，每天都要打开的文档（计划本、日记、速记本）每次都得去文档树里翻找，入口太深。

悬浮球把这些入口变成一颗颗可摆在界面任意位置的按钮。绑定快捷键的球，点击等价于按下该快捷键，移动端因此也能用上原本键盘专属的功能；绑定文档的球，点击打开、再点关闭，还支持以标签页、弹窗等形式打开。球可以拖到顺手的角落，位置会自动记住，且桌面端与移动端各自独立记忆。

例如放一颗绑定 Alt+0 的球，随时随地开始闪卡复习；放一颗绑定「遍历 Daily Note」快捷键的球，翻阅近期日志只需连点几下。进一步的玩法是把计划文档绑定到悬浮球、配合 Daily Note 形成动态计划系统，见文末「进阶用法」。日常放两三颗最常用的入口即可，比多记一堆快捷键更省心。

## 快速上手

在番茄工具箱设置的「悬浮球」板块打开总开关。桌面端与移动端的绑定列表相互独立，可以分别添加「文档」或「快捷键」绑定，已有的绑定项可以随时删除。

## 进阶用法：悬浮球 + Daily Note 动态计划系统

[图片]

一种核心用法是对 Daily Note 的补充与功能延伸，形成动态、可调整的计划管理体系。其关键在于利用两个工具的协同作用：

1. **悬浮球绑定计划文档：管理长期与优先级任务**

- Daily Note 每日生成新文件，天然不适合存放需长期跟踪或频繁调整的计划任务
- 通过悬浮球功能绑定一个固定的计划文档，可实现该文档的一键快速打开与关闭，显著提升操作效率。
- 在该计划文档中，采用层级列表管理任务：

- **优先级排序**：将最优先执行的任务置于列表最顶端。
- **动态调整**：任务的优先级可随时通过上下移动位置进行调整。
- **任务分解**：当一个任务衍生出子任务或新分支时，直接在其下方添加子列表项进行细化管理。
- 这种动态管理既避免任务堆积，又省去反复设置日期的繁琐。

1. **Daily Note 定位：专注当日执行与记录**

- Daily Note 核心作用在于记录每日具体的执行情况，涵盖：

- 学习/工作内容与进展
- 个人生活事项与感悟
- 当日实际完成的任务（可能来源于计划文档）

1. **系统协作：构建弹性优先级计划流**

- 悬浮球绑定的计划文档负责宏观框架与动态优先级排序，确保核心任务清晰可见且可灵活调整。
- Daily Note 负责微观执行与当日记录，反映计划的实际落地情况。
- 两者配合：计划文档提供目标指引与待办池，Daily Note 反馈执行状态并可能催生新任务/调整需求，形成闭环。这种分离设计有效解决了长期计划与短期执行的矛盾，共同构建了一个兼具目标导向（计划文档）与执行反馈（Daily Note）、并能灵活响应变化（动态排序+子任务）的高效计划系统。
