# 渐进学习 Progressive Learning

让长文真正读得完：把长文档拆成每天读得完的份，从阅读输入到闪卡复习的完整闭环，全部开源。

## 核心亮点

- 📖 **两种渐进模式**——摘抄式（选精华）与分片式（整篇切片），长文按天消化，不再收藏等于读过
- ✂️ **拆文工具箱**——断句拆分、回车拆块、合并块、移动端双击多选，输入端顺手
- 🎴 **制卡一条龙**——多行挖空、多行制卡、单词闪卡、Daily Card，读到哪卡到哪

## 功能总览

### 📖 渐进阅读

- **摘抄式渐进学习**——选中即摘抄，精华进队列，按天读
- **分片式渐进学习**——整篇文档自动切片，每天读一片

### ✂️ 阅读与编辑辅助

- **断句拆分**——长段落自动断句成块
- **按回车拆分块**——回车即拆，输入顺手
- **合并块**——多块合一
- **移动端双击多行选择**——手机上快速选段
- **划词解释**——选中即查，词义即时呈现

### 🎴 制卡与复习

- **单词闪卡**——生词一键成卡
- **多行挖空**——多行内容挖空制卡
- **多行制卡**——问答卡批量制作
- **Daily Card**——每天一张卡，日常积累
- **显示拼音**——汉字标注拼音

## 上手

1. 打开一篇长文，选中想读的文字，浮条点「执行摘抄」；或者用命令「添加当前文档到渐进阅读分片模式」把整篇切片
2. 命令面板执行「开始学习」，按节奏读当天份，读完翻页
3. 想记住的重点：选中后挖空/制卡，复习走思源自带闪卡体系
