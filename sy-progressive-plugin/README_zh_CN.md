# 渐进学习 Progressive Learning

让长文真正读得完，让作品真正写得完：渐进阅读消化输入，渐进写作产出作品——从阅读到写作的完整闭环，全部开源。

## 核心亮点

- ✍ **渐进写作**——素材排队写：任意文档的选中块直接入槽，滚筒每天推你写一片，写完定稿、汇编成稿。读到的精华，就是你下一篇作品的原料
- 📖 **两种渐进模式**——摘抄式（选精华）与分片式（整篇切片），长文按天消化，不再收藏等于读过
- ✂️ **拆文工具箱**——断句拆分、回车拆块、合并块、移动端双击多选，输入端顺手
- 🎴 **制卡一条龙**——多行挖空、多行制卡、单词闪卡、Daily Card，读到哪卡到哪

## 功能总览

### ✍ 渐进写作

- **写作书**——书名加大纲建书，一行大纲一个槽位，想写什么先搭骨架
- **素材三通道入槽**——任意文档选中块直送、摘抄池拉取、浮条直接入槽；素材带出处徽标，点击跳回原文
- **同一滚筒排队写**——阅读书与写作书同一调度：阅读是别人写好的内容排队读，写作是你的素材排队写
- **片管理**——素材多了拆新片、移片增援、写完定稿（可逆）
- **汇编成稿（Pro）**——定稿的片一键汇编成独立文档，从素材到作品一步到位；日常写作流全免费

### 📖 渐进阅读

- **摘抄式渐进学习**——选中即摘抄，精华进队列，按天读
- **分片式渐进学习**——整篇文档自动切片，每天读一片

### ✂️ 阅读与编辑辅助

- **断句拆分**——长段落自动断句成块
- **按回车拆分块**——回车即拆，输入顺手
- **合并块**——多块合一
- **移动端双击多行选择**——手机上快速选段
- **划词解释**——选中即查，词义即时呈现

### 🎴 制卡与复习

- **单词闪卡**——生词一键成卡
- **多行挖空**——多行内容挖空制卡
- **多行制卡**——问答卡批量制作
- **Daily Card**——每天一张卡，日常积累
- **显示拼音**——汉字标注拼音

## 上手

1. 打开一篇长文，选中想读的文字，浮条点「执行摘抄」；或者用命令「添加当前文档到渐进阅读（加书）」把整篇切片
2. 命令面板执行「开始今日阅读」，按节奏读当天份，读完翻页
3. 想记住的重点：选中后挖空/制卡，复习走思源自带闪卡体系
4. 想写点什么：舰队面板「新建写作书」搭槽位，平时看到的好素材选中直送入槽；滚筒每天推你写一片，写完定稿，最后「汇编成稿」一键成文
