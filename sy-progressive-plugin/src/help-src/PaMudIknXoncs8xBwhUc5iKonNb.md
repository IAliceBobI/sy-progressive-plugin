## 闪卡策略

摘抄进闪卡复习有三条路，按需组合：

1. **背诵去向**：子排「背诵」把这一条摘抄直接制成文档级闪卡——最顺手的一条路；
2. **每日卡**：设置 → 摘抄与制卡 →「摘抄加入到 dailycard 当天目录下」打开后，每条摘抄自动发到当天的 Daily Card 目录，与当天制卡汇合；
3. **手动制卡**：摘抄文档就是普通文档，随时用制卡快捷键对它制卡（快捷键任意文档可用，见下一节）。

**附属卡**：浮条上的「附属卡」按钮（书 / 分片 / 摘抄态都有）打开 digest-书名 文件夹的闪卡复习——复习范围按文件夹过滤，只刷这本书的摘抄卡；有到期卡时按钮带「· 到期 N」胶囊提醒。闪卡的间隔、难度全部交给思源官方 FSRS 调度，渐进不另起炉灶。

摘抄攒多了，一次性复习几十张卡会有压力？配合 [番茄工具箱的均匀推迟功能](https://awx9773btw.feishu.cn/docx/KwZJdW9BeoHkiRxVg6jcLUnanqf)，可以把当前文档和子文档里的全部闪卡复习时间均匀打散到指定时间范围内。

**旧版用户看这里**
- 旧「单 / 多模式」切换（Alt+Z → 卡片图标）已随菜单改版移除：新摘抄默认不自动入卡，要入卡走上面的「背诵」或「每日卡」；存量书上设置过的策略继续生效——单模式的书，闪卡始终只在最新一条摘抄上，新摘抄入卡时旧卡自动移除；
- 🔨「完成标记」退役后，旧文档里「标记完成 → 闪卡转移到其他摘抄」的机制一并退役；终结推送用「归档」，闪卡想清掉就直接删卡。

## 制作闪卡

制卡是核心复习流，**全部免费**。四个通道一张表看全——任意文档都能用（分片、原书、摘抄文档、普通文档皆可，快捷键全局生效，只读模式也行）：

| 操作 | 快捷键 | 制出的卡 |
|-|-|-|
| 制卡 | Alt+E | 选中多行 → 多行合卡；光标不选 → 整块制卡；**拖蓝选中文字 → 挖空卡**（高亮处复习时先隐藏） |
| 多行标记 | Shift+Alt+Enter | 挖空的预备动作：有拖蓝标记拖蓝文字，无拖蓝对光标块切换高亮，反复点加 / 去 |
| 原地制卡 | Alt+\` | 卡插在光标块下方、不跳转，读到哪里制到哪里 |
| 制卡无引用 | Alt+S | 同 Alt+E 流程，但卡片不带原文回链 |

右键菜单也能制卡：设置 → 菜单入口 →「添加右键菜单: 制卡」打开后（默认关闭），右键任意块，插件子菜单里就有「制卡」项——点选即整块制卡，落点与快捷键制卡一致。

卡的形态是**超级块**：内容行在问、空行以下是答——复习时先看到问，翻面看全文。卡片默认并入当天的 dailycard 文档集中收纳（设置「制卡并入 dailycard」可关闭；关闭后收进 prog-data 旁的 cards-书名 文档，此时「卡片挂在分片下」开关决定挂在书下还是当前分片里）。开启设置「卡片最上面添加相关概念」后，卡内会带一条块引用锚（@ 文本），点击直接跳回原文块；原文块上也会出现被引用角标（思源原生的引用计数，点角标可看到引用它的卡），已制过哪些块在源文档里一眼可辨。可再加制卡时间戳，回溯出处一目了然。

（图：cards 文档里的两张卡：上图挖空高亮卡，下图多行合卡）

**一键加闪卡**（联动）：装了「仿写练习」插件的话，仿写练习的浮条上有「加闪卡」按钮——把当前练习文档**整体**加入官方快速卡组，与摘抄卡同组混排复习，重复点击不会重复加卡。

## 生词：收集与 AI

读到生词，**先拖蓝选中**这个单词或短语（块选中不算），再点子排里的去向：

- **单词**（免费）：收录进 prog-data 的 words-书名 文档——一条超级块词条：生词 + 点击回原文锚点的回链 + 六个词典快捷链接（有道 / 深言达意 / 百度 / 知乎 / 谷歌 / 必应），随手查、随时回；
- **生词 AI**（Pro）：在收录的同时让 AI 基于上下文给出双语简释与例句，写进词条下方——用思源「设置 → 人工智能」里配置的模型；未激活时收录照常完成，AI 部分跳过并给出解锁引导。

单词本是长期资产：换设备、挪位置都按 ID 认回；旧版本建的 words 文档同样原位认领。想给生词制卡，在单词本里对词条按 Alt+E 即可，流程与普通制卡完全一致。

（图：words-书名 单词本：词条带回原文锚点的回链与词典快捷链接）

## 重访调度与问题心得

有一类内容不适合闪卡的硬排期——一个没想通的问题、一个想定期回顾的段落。重访调度是给它们的**温和闹钟**：不进闪卡、不打分，两种模式：

| 模式 | 节奏 | 适合 |
|-|-|-|
| 曲线（问题） | 3 天起步，每次 ×2，封顶 60 天 | 没想通的问题：「还没懂」就推迟（间隔翻倍），想通了转心得，从此不再打扰 |
| 日程 | 每 N 天一轮（1 / 3 / 7 / 14 / 30 天，可改可移除） | 周期性回顾：完成一轮自动进入下一轮 |

入口与动作：

- 子排「**思考**」= 摘抄并标为问题（曲线模式起步）；
- 子排「**重访调度**」= 给选中块设 / 改 / 移调度，档位菜单里选模式与间隔——任意块都能挂，不限于摘抄；
- 右键带调度标记的块，菜单直接给动作：曲线是「问题已解决 / 还没懂稍后再看」，日程是「本轮已完成 / 推迟到明天」；右键还能「标为心得 / 取消心得」，手动把任意块收进心得。

**到期提醒**：舰队总览的书卡上有 ✧ 徽章显示到期问题数，**点击徽章**打开到期待办列表，逐条完成 / 推迟 / 移除；✱ 徽章统计心得数。整个队列的哲学是温和：到期不弹窗、不施压，只是把「该回来看一眼」的清单替你攒着。

（图：✧ 到期待办：点击书卡徽章逐条完成 / 推迟 / 移除）

## 阅读曲线接管（实验）

实验功能，**默认关闭**。打开它，「今天该读什么」不再只躺在舰队里——各书的下一片直接进官方闪卡复习界面，与你的制卡、生词卡按到期时间自然混排：打开复习（⌃0），分片卡带着「渐进阅读」小标出现，读完点「**下一张**」（或空格 / 回车）即确认读完——插件记账摘卡、滚筒续推下一片。编辑器里读片推进照旧，两个入口一本账。

| 你看到的 | 实际语义 |
|-|-|
| 每日额度 | **每书闸门**：每书每日 q 片（默认 3，随每日额度档）；当天用完，下一片自动排到明天 0 点 |
| 舰队「欠债」 | **全天总量**口径（Σ各书缺口），与复习界面看到的每书投影是两个数字，口径不同都正常 |
| 「下一张」 | 评分=读完确认：记一片、摘卡、续推（对齐官方「良好」评分语义，无间隔曲线） |

几个行为先说清，免得意外：

- **翻页是快照**：复习界面打开时取当期队列——刚读完续推的新片不插进当前队列，重开复习界面就能看到下一片；
- **跳过会被复活**：阅读卡点「跳过」不计读，下一轮巡查把它重新拉回到期；不想读请去编辑器推进或调额度；
- **手动改期会被覆盖**：阅读卡的复习时间由巡查统一接管，手动改的到期时间会在下一轮巡查被改写回来；
- **预建片可见**：接管建出的片是普通文档，编辑器里可见可读；
- **与片内制卡并存**：片内制的卡（挖空、合卡）与分片卡会先后出现在复习界面——同一内容两次属正常，各管各的调度；
- **关闭即清场**：关掉开关会摘除全部阅读卡并清理标记；巡查频率档（30 分钟 / 1 小时 / 6 小时）只调后台定时对账的节奏，关掉定时仍有事件驱动的对账。

设置位置：设置 → 制卡 → 「阅读曲线接管（实验）」。
