# 渐进学习 · 收费与附录

这一篇收拢**收费与激活、设置导览、快捷键、数据存放与自定义、常见问题**。

## 收费与激活

**核心阅读流程永久免费**：加书、滚筒阅读、摘抄、挪片、制卡、全部视图——不花钱也能完整走通「加书 → 读 → 摘抄 → 复习」的主线。

**Pro ￥72 买断一个价**，终身有效，包含：

- **皮肤系统**——配色主题 × 火苗形态 × 容器材质三维混搭，加参数微调与未来新皮（见「皮肤系统」章）；
- **断句三档**——重插菜单的段落 / 任务 / 列表三档（「按书设置」与「不断句」两档免费，见「重插与断句」章）；
- **生词 AI**——AI 翻译与例句（生词收录本身免费，见「生词」一节）；
- **收集与写作对比族**——提取笔记、提取全部、提取到底、合并、收集、去色、恢复颜色；
- **同步解锁「仿写练习」插件全套**（含 AI 拆分）——买一份渐进 Pro，两个插件的付费功能全部到位。

**老用户零操作**：原有激活码直接生效，无需重新激活、无需补差价，升级后自动过门。永不降价只增值——后续新功能持续并入 Pro，已购自动包含。

## 设置面板导览

两个入口：左 Dock「舰队总览」面板右上角的「设置」按钮，或快捷键 Shift+Alt+,（可改）。面板为双栏结构：左侧是九个功能域的导航，右侧只渲染当前域的设置项；顶部搜索框一输入就切到「全部」聚合视图——全域设置同屏、命中域在导航上高亮，点击即跳，找开关不用逐域翻。

九个功能域：

- **摘抄**——摘抄落点四档（集中归档 / 源文档下方 / Daily card 目录 / 当前文档子文档）、已摘抄块显示背景色、入槽素材胶囊显示边框等摘抄行为开关；
- **制卡**——制卡落点三档（当日卡文档 / 当天日记 / 卡片夹）、卡片来源路径三档（关闭 / 仅文章名 / 完整路径）、制卡时链接原文块、摘抄制卡模式、修订痕迹色条，以及「阅读曲线接管（实验）」设置块（接管开关、巡查频率与分片 / 素材 / 摘抄 / 阅读点 / 文档卡五类推送开关）；
- **浮条**——「移动端浮条固定顶部」开关 +「浮条入槽按钮」开关（默认开；「直接入槽 / 入槽」两钮**有在写的书才显示**，关掉即恒不出现）+ 片态首行按钮池：32 个按钮自由勾选去留（7 个主排池钮 + 3 个托盘 + 8 个低频 + 14 个高级）；
- **皮肤外观**——配色 × 火苗 × 材质三维货架与参数微调（见「皮肤系统」章）；
- **基础设置**——新开窗口的打开方式（7 档：不打开 / 前台页签 / 后台页签 / 右侧分屏 / 底部分屏 / 独立窗口 / 瞄一眼自动返回）、新闪卡存入的笔记本（默认跟随当前文档）、禁用初始化浮动按钮、片尾收束卡总开关；
- **菜单入口**——渐进右键菜单项的显隐开关：整篇摘抄、重访调度、复访节奏三项默认开启，加书、摘抄模式、制卡、跳到分片/原文四项默认关闭（浮条与快捷键已覆盖同款能力，关掉的随时可开回——「制卡」开关打开后任意文档右键即见制卡项）；
- **快捷键**——全量命令的键帽（20 余枚），点击即可改键（见下一节）；
- **数据管理**——prog-data 路径显示与「归拢摘抄 / 放回源文档下」双向搬运（散落各处的摘抄夹一键收进总夹，或反向放回各来源书/源文档正下方）；
- **AI 接入**——把 AI 助手接进思源的接入引导（详见「AI 接入（MCP）」篇）。

## 数据存放与 CSS 自定义

### 摘抄数据集中在 prog-data

所有摘抄产物集中收纳在 prog-data 文件夹（可自由改名、移动，插件按 ID 认回）：

- 每本书一个 digest-书名 文件夹，一条摘抄一个文档；
- 无书归属的摘抄与书并排进摘抄总夹（digest-源文档名）；
- 单词本（words-书名）与每日「阅读日志」也在这里；
- 散落的摘抄夹在 设置 → 数据管理 →「归拢摘抄」一键收拢进总夹；想搬回原处用对称的「放回源文档下」（找不到来源的夹会列名不动）。摘抄落点在「集中归档 ↔ 源文档下方」间切换时，也会主动询问要不要把现有摘抄夹一起搬。

### 用 CSS 自定义笔记颜色

v3.0.0 起片内不做任何色彩修饰——原文与手写笔记同为默认色。想要自己的配色，把下面的 CSS 片段添加到 思源设置 → 外观 → 代码片段（CSS），把 color 值改成喜欢的颜色即可。两段分别命中片内新写的句子块与「提取的笔记」块，原文块不受影响；Pro 的「去除笔记颜色」按钮会让对应块退出这些染色（「恢复笔记颜色」撤销）。

改变分片笔记的颜色：

```CSS
.protyle-wysiwyg div[custom-progref][custom-paragraph-index]
:not([custom-prog-origin-text])
:not([custom-prog-key-note])
:not([custom-prog-key-no-color]) {
    color: rgb(156, 15, 178) !important;
}
```

改变提取的笔记的颜色：

```CSS
.protyle-wysiwyg div[custom-prog-key-note]:not([custom-prog-key-no-color]) {
    color: rgb(156, 15, 178) !important;
}
```

## 常见问题

- **免费和 Pro 的边界在哪？**——核心阅读流程永久免费：加书、滚筒阅读、摘抄、挪片、制卡、全部视图。Pro ￥72 买断=皮肤系统、断句三档、生词 AI、收集与写作对比族，并同步解锁「仿写练习」全套；未激活时 Pro 功能灰档可见。详见「收费与激活」一章。
- **制了卡，复习界面里却看不到？**——若用的是多行合卡（超级块卡）或摘抄文档卡（背诵去向）：思源默认在 设置 → 闪卡 里关闭了「超级块」与「文档」两种卡片类型，这份默认配置下加卡会被静默跳过（无报错）。去 思源设置 → 闪卡 打开「超级块」「文档」两个开关并重启思源即可。挖空卡不受影响。
- **复习时弹「请打开笔记本 [X] 后再试」？**——这是背诵卡（引用块卡片）引用的摘抄源在那个已关闭的笔记本里，思源原生提示，跟插件版本无关。翻到这类卡时卡面顶部会出现提示条：**跳过这张** 直接翻走、**移除背诵卡** 把卡摘出复习队列（摘抄文档保留）。详见复习篇「几个行为先说清」。
- **手动分片的书，点书卡打开的是摘抄？**——设计行为：手动书的「片」就是你的摘抄，点书卡直达最近一次摘抄（续读）；还没摘过时打开原书让你直接摘抄（摘抄即片）。详见「手动分片书：摘抄即片」一节。
- **删掉的分片为什么又出现了？**——原文再次被读到时会重建对应分片；分片是一次性的，读完即删，不想要的分片不读它就行。
- **可以修改分片或摘抄文档的标题吗？**——可以；prog-data 文件夹和里面的文档也都能改名、移动，插件按 ID 认回。但分片文档的备注别改，插件依赖备注定位。
- **删除分片后，它的闪卡也没了？**——是的，删除分片会一并删除它本身的文档闪卡，不影响文档内的其他闪卡。
- **片内的双色 / 原文灰显去哪了？**——v3.0.0 起退役：片内原文与手写笔记同为默认色，不做任何色彩修饰。想要自己的配色见「数据存放与 CSS 自定义」的两段 CSS 片段。
- **旧版摘抄把背景色写进了原文，怎么清？**——v3.0.0 起摘抄痕迹不再写入原文（渲染态竖条 + 可选背景）。旧版留在正文里的背景色需手动清除；相关旧开关已移除。
- **换电脑 / 重装后怎么找回激活？**——登录同一个思源账户，打开解锁框点「找回激活码」云端找回；或直接粘贴原激活码。详见「收费与激活」一章。
- **巨书加书、打开大纲会很慢吗？**——不会。v3.0.0 换用大纲专用接口，巨书首开从半分钟级降到 0.2 秒级，5 分钟内重开秒出。
- **移动端能用吗？**——能。浮条在移动端自动切换为顶栏形态，详见「移动端」章。
- **旧版「计划读完时间」去哪了？**——已移除，由「档位 + 滚筒」接管：每天固定片数、欠债滚动，比死天数更贴合实际节奏。
- **仿写练习去哪了？**——独立成了「仿写练习」插件；渐进学习的摘抄可一键送仿写，渐进 Pro 同步解锁仿写全套（见「仿写联动」章）。
- **许可变更是怎么回事？**——自 v3.20.0 起，本插件改用专有许可：个人使用仍然免费，个人用户无任何变化；禁止再分发、改包分发与绕过激活校验；商用（向使用者收费、付费服务、企业内部使用）需书面授权——QQ 频道或飞书群联系。v3.19.0 及更早的历史版本仍按发布时的 MIT 许可提供。
