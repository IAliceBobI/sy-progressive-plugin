# 开始

## 渐进学习是什么

渐进学习（也称「渐进阅读」）把长文档拆成小片段，配合思源自带的闪卡复习，让你能同时推进多本书籍和材料，而不是一本书读到一半就搁浅。

它替你做三件事：

- **拆**：把整本书按标题或字数切成一片一片的「分片」，每天读几片由你定；
- **读**：打开的分片就是一个普通文档——随便划线、写笔记、改写、制卡；
- **存**：摘抄、笔记、单词、闪卡自动归拢到 prog-data 文件夹，进度与复习体系都由插件打理。

**一图流：你在哪些「地方」之间流转**
主循环：普通文档 →（加书 · 切分）→ 书 →（今日阅读 / 继续读）→ 分片 →（读完翻下一片）；中途 🔄 换书随时跳到下一本书。
分片上的四条产出线：✏️ **改写**（直接改内容，读完合并成新书）｜📝 **笔记**（随手写，提取归总）｜✂️ **摘抄**（留档 / 背诵 / 单词 / 送仿写）｜🗃️ **制卡**（挖空卡、无引用卡、并入 dailycard 归档）。

核心阅读流程永久免费。Pro（￥72 买断）解锁皮肤系统、断句档位、生词 AI 与收集/写作对比族，并同步解锁「仿写练习」插件全套——详见「收费与激活」一章。

## 快速上手（三步）

1. **添加文档**：打开一篇较长的文档，按 Shift+Alt+M（或浮条 📥、插件菜单「添加当前文档」），在弹窗里点选切分方式；
2. **开始今日阅读**：点状态栏火苗，或左 Dock「舰队总览」面板的「▶ 开始今日阅读」（Alt+-），滚筒按书序出片，逐片阅读、做笔记、制闪卡；
3. **复盘**：舰队总览看书卡进度与近 14 天热力，✒ 摘抄 / ✱ 心得 / ✧ 问题到期徽章提醒你回来收拾。
**今日阅读计数怎么 +1**：读到新片的那一刻就计 1——分片浮条的「下片删」（删除本片、进下一片）和「下一个分片」（只翻页、片留着当草稿）同权计数，「回看」不计，回看后再前进也不会重复刷高。火苗与「开始今日阅读」只负责打开分片、本身不计数；轮到写作书开片则同样 +1。

三步各自的细节在后面各章展开：加书与切分、今日阅读、浮条工作台、舰队总览。只想先跑起来，跟着上面三步走就够了。

## 两种模式怎么选

| 对比项 | 分片模式 | 摘抄模式 |
|-|-|-|
| 拆分方式 | 按标题 / 文本长度自动拆分整篇文档 | 阅读时手动选中内容块摘抄 |
| 适合场景 | 整本书、长文档的系统渐进阅读 | 边读边摘、对导入书籍做精读摘录 |
| 入口 | 浮条 📥 或 Dock「舰队总览」加书，Shift+Alt+M | 选中内容后按 Alt+Z |

两种模式可以同时使用（分片也能被摘抄，相当于手动挡的精读）。若想以「书」的名义管理这类摘录——进舰队、有书卡与徽章——建书时勾「手动分片」即可，见「手动分片书：摘抄即片」一节。文中快捷键统一用 Windows 写法（Ctrl / Alt），macOS 上分别对应 ⌘ / ⌥。

## 使用路线图：站在任何节点，知道能去哪

渐进学习里你会在几种「地方」之间流转：普通文档、书（原文）、分片、摘抄文档。主循环只有一条：**普通文档 →（加书，按规则切成 N 个分片）→ 书 →（今日阅读 / 继续读）→ 分片 →（读完翻下一片）**；途中 🔄 换书随时跳到下一本书的今日分片。站在分片上，有四条产出线可以走：

| 产出线 | 你做什么 | 得到什么 |
|-|-|-|
| 改写线 | 直接在分片上修改内容 | 读完「合并所有分片为新文件」→ 一本加工过的新书，可再添加开始新一轮 |
| 笔记线 | 在分片里随手写笔记（你新加的块会被自动识别） | 「提取所有分片的笔记」→ 归总的笔记文档；「收集」把选中块收进本书汇总文档 |
| 摘抄线 | ✂ 选中内容摘抄 | 摘抄文档——留档（默认）、思考（3 天后重访）、背诵（同时进闪卡）、单词、整篇副本、送仿写 |
| 制卡线 | 制卡类按钮 | 闪卡，可选发到 DailyCard |

回流与跳转，让产物随时能回到阅读现场：

- **摘抄文档 → 原文**：点浮条「回原书」定位到原文块；反过来，原文上有竖条印记的块，点印记即跳到对应摘抄，一处以上会弹列表挑选。
- **分片 ↔ 原文**：浮条「打开原书」按钮开原文；右键块「跳到分片或回到原文」（Shift+Alt+W）双向定位。
- **摘抄上可以再摘抄**（收入札记匣），也能一键「送仿写」——仿写就是在摘抄上进行的，印记与回原文能力都保留。

记不住这些也没关系：浮条平铺区的 🗺 **路线指引**按钮（四态都有）会列出「你在这里，能去哪」——当前文档类型能走的每条路都在浮层里，书态还带「设为仿写原文」的联动入口。
