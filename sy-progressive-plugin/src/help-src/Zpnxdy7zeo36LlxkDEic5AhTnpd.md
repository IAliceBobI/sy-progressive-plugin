# 渐进学习 · 渐进阅读

这一篇讲**渐进阅读**的全部玩法：把长文拆成小分片，滚筒每天按节奏推给你读。

## 加书：切分设置

入口有三处：打开一篇较长的文档后按 **Shift+Alt+M**、插件菜单或文档树右键「加入渐进阅读」（右键入口恒显，不用先打开文档），或任意浮条上的 **📥 加书**按钮（书 / 分片 / 自由态常驻）。弹窗分成两块：

- **文档统计**：总字数、总内容块数、各级标题数，以及按当前切分设置的**预计分片数量**与最短 / 中位 / 最长片长——改动设置，数字即时刷新；
- **切分设置**：标题级别点选 + 每片字数滑块。标题级一行里「×N」是该级标题总数，带「推荐」标记的是插件按目标片长替你试算的落点；字数档位为 不限 / 500 / 1000 / 2000 / 3000 / 5000 / 8000，**默认 500** 字一片。

（图：加书弹窗：统计随切分设置即时刷新（图为 4.5 万块的《冰与火之歌》））

三种切法，可单独用也可组合：

- **按标题拆分**：勾选作为切分边界的标题级（H1\~H6）。勾选 B 时，独占一行的粗体也当成标题——适合没有标准标题层级的书；
- **按文本长度拆分**：累计到设定字数就切一刀。字数按字符计（编程里的「字符串长度」），天然兼顾中英文；
- **标题 + 文本长度**：先按标题分组，组内再按字数切——适合一个标题下内容太多的情况。

几个老规矩都还在：

- 拆完觉得分片太大？**支持对分片再次拆分**，也可以先通读一遍按自己的理解加标题再拆；
- 巨书不怕：四五万块的大部头，统计与预览照样秒出（目录 / 大纲浮层走专用通道，首开 0.2 秒级）；
- 加书不会改动原文档一个字——书保持锁定，分片随便造。

## 目录成书：一个文件夹当一本书

有一类材料天然是「一篇篇文章」：教程合集、专栏连载、按章节组织的书。把它们压成一整篇文档再加书很别扭——现在不用了：**对一个父文档加书时，弹窗顶部会出现「成书方式」选择**，选「目录成书（N 篇）」，子文档就是文章池：

- **读书顺序 = 文件树顺序**：想调整阅读顺序，直接在文件树里拖动子文档；
- **分片挂在各自文章下**：序号全书连续（[00001]、[00002]…跨文章不中断），但每片都挂在它的来源文章下面——翻文件树就能找到「这段出自哪篇」；
- **短文单独成片**：几十字的小文章也是独立的一片，不会和前一篇拼在一起；
- **移动 / 删除文章随时可以**：下次推送时插件会自动按新的文件树顺序重排分片并校正阅读进度——读到哪篇文章的第几片，重排后还是那篇的那片。
- **新增文章**：往文件夹里新加的子文档不会自动进书（占位 0 片、不推送），想让它进阅读顺序，重新打开加书弹窗走一遍「重新分片」即可。

原文是只读参照：直接修改文章内容不会同步进已建的分片，需要按新内容重切时，重新打开加书弹窗走一遍「重新分片」即可（与单篇书同一语义）。默认选法仍是「单篇成书」——父文档自己的正文照旧可以单独成书，老书的行为没有任何变化。

（图：加书弹窗的「成书方式」：选中「目录成书（3 篇）」后子文档就是文章池，文档统计与分片预估按整目录刷新）

## 物理分卷：巨文档先拆再读

三百万字的大部头整篇放进思源，打开慢、保存重。**在文档树右键这篇文档 →「物理分卷」**，勾选作为切分边界的标题层级、选好切分方式，预览确认后切成几个子文档：

**切分方式两档**：

- **按体量**（默认）：体量划大类——在所选标题层级里找断点，凑满每卷字数上限就切一卷，不会硬切在字中间；
- **按结构**：不管字数，每 N 个所选级标题切一卷（默认 1，即「一编一卷」）；目录、序言等第一个断点前的内容自动单独成卷，超长的卷只标黄提醒、不会被拆开。

多个标题合并成一卷时，卷名后会带「 等2编」这样的计数角标（编/章/节/部/回/篇/卷自动识别），一眼看清这卷收了几个标题。

- **原文档变成目录壳**：正文搬进各卷子文档，原文档自己只留一个空壳当书的封面——之后照常加书，就是上面说的「目录成书」；
- **想找回原文**：编辑器「文件历史」里能恢复（保留期跟随设置里的历史保留天数）；
- **已是渐进书籍的文档也能补切**：切完会按新结构重新分片，阅读进度重置（与「重新分片」同一语义）。

分卷只是物理组织——日常推送的粒度仍然是细片（六十万字一卷照样拆 [00001] 起的小片），阅读节奏不受影响。复制走 Markdown 通道，个别特殊块（数学公式块等）样式可能简化；;;; 自定义块不建议经此工具搬运。加书弹窗也会主动提醒：单篇超过 50 万字的书，顶部会出现「建议先物理分卷」的提示条。**分卷书首次打开**的默认展示档按书自适应，卷预览打开不会一片空白；空态文案也带上分卷数字引导，照着提示走就能落到第一片。

（图：文档树右键「恒星编年史」→ 插件子菜单里的「物理分卷」入口）

## 手动分片书：摘抄即片

法律条文、诗词集这类材料，边界交不出给标题或字数——第几条就是第几条。对它们可以在加书时**不自动切分**：「分片选项」卡里勾上**手动分片（不自动切）**，切分与断句配置随之置灰（用不上），点确定即建书。

手动分片书的书身份照常注册——进舰队、有书卡，摘抄照常落进 digest-书名 夹，书卡 ✒ 徽章照常聚合。不同的只有一件事：**没有自动分片，片由你的摘抄产生**。

**手动分片书也进换书轮转**（v3.14.0）：轮到它时自动打开原书并定位到上次读到的地方——优先用阅读点（F7 设置的那个），没设过就跳最近一次摘抄的原文位置，都没有则从书头开始。只要还在摘抄，手动书就一直在轮转池里；读完备归档即退出。轮到一次照常计入当日阅读量，与自动切片书同一套节奏（书卡/浮条点击打开仍是直达最早一篇摘抄）。

- **摘抄即片**：在原书里选中内容，浮条「摘抄」子排选去向（或快路径 Shift+Alt+Z），这一次摘抄就是一片；每次读多少、摘多少，边界完全由你定；
- **点击书卡 = 直达最早一片摘抄**：手动书的「片」就是摘抄，点书卡、「开始今日阅读」会打开**最早一次摘抄**——手动书没有续读指针，从最早一篇推进才与自动书「从第一片开始」的语义一致；还没摘过时回落为打开原书并提示「请直接摘抄」；
- **滚筒不推送新片**：手动书没有可推的分片——轮到它时是打开原书让你续读（同上）；手动书计入当日阅读量但没有档位上限，读满也不会被移出轮转池；书架可读的书只剩手动书时，会提示点书卡打开；
- **片的复习走摘抄的路线**：摘抄是否成卡由「摘抄制卡模式」决定（背诵去向即卡、进附属卡复习），也可事后在摘抄文档里手动制卡——见「摘抄：子排与去向」与「闪卡策略」。

想改回自动分片：管理页（舰队总览 → 管理书目）该书展开后点**重新分片**，重开加书弹窗按常规方式切分。反过来，自动书转手动会**清空旧索引与全部分片**（提示「正在清理旧分片…」），已有摘抄文档不受影响。

## 今日阅读：滚筒与档位

渐进学习不排「计划读完时间」，而是每天一个**档位**，插件按书序轮转出片：

- **档位**：轻 1 / 常 3 / 冲 5 片（默认 3），在左 Dock 舰队面板顶部随时切换；
- **滚筒轮转**：每出一片指针推进一格，多本书雨露均沾；
- **当日配额**（v3.20.0）：一本书当天读满档位数（轻 1 / 常 3 / 冲 5）后，滚筒当天不再轮到它出新片——回看旧片、续读当前片不受限，想连读同一本就点书卡或用浮条 ➡「下片删」；满了但不想再读这片（明天也不想），用平铺区「删片换书」：删掉本片直接轮到下一本书，不走额度、明天不会重推（v3.21.0）；在轮转的书全部读满时，滚筒提示「明天再来」；
- **欠债**：当天没读满档位记欠，读满封顶、超额不抵扣。状态栏火苗是仪表灯——**绿**=今天已清、**黄**=还有欠、**红**=连续两天没读；
- **断点续读**：每本书记住读到哪，舰队书卡点击直达。默认全书共用一个阅读点（换片顶替）；开启设置里的「阅读点每文档独立」后，同一本书不同分片可各自设阅读点并存、互不顶替，每点独立制卡；
- **重置阅读进度**（v3.20.0）：想重读或换个起点，三个入口——完读的书在**书卡右键「重新阅读（从头）」**（整本读完时也会弹窗询问是否重读）；原书里**右键「从这里开始学」**（同「重新阅读」一样只对完读的书显示；在读书右键对应项是「跳到分片或回到原文」）把断点钉到当前块所在片；片内浮条**「重置到此片」**把断点钉到当前片。摘抄、复习曲线、当日阅读账全保留，重读不重复计数；
- **读完即删**：分片是一次性的，读完即删，原书不动；整本读完可在浮条「归档本书」，摘抄集永久留存。

快捷键：开始今日阅读 **Alt+-**；随机打开一本书的随机分片 **Alt+Shift+-**。想连读同一本，用分片浮条的 ➡「下片删」（删片前进，不动滚筒指针）。

## 回访频率：重温的快慢

开启「阅读曲线接管」（见「闪卡与复习」篇）后，重温中的摘抄会按固定节奏回来见你：3 天后第 1 次，之后间隔翻倍（6 / 12 / 24 / 48 天），满 5 次毕业、不再打扰。**回访频率**调的就是这条节奏的快慢：

| 档位 | 相邻两次的间隔 | 适合 |
|-|-|-|
| 高 | 约 2 / 4 / 8 / 17 / 34 天 | 新读的、想盯紧的书 |
| 中（默认） | 3 / 6 / 12 / 24 / 48 天 | 现状——不动它，体验与从前完全一致 |
| 低 | 约 5 / 9 / 18 / 36 / 72 天 | 内容已熟，只想偶尔照面 |

无论哪档，「间隔翻倍、五次毕业」的骨架不变；改档也不重置进度——第几次还是第几次，只是下次见面按新间隔重排。

入口三处，随点随改：

- **书卡右键 → 回访频率**（或管理书目页该书一行的档位钮）：整书生效——已在重温的摘抄批量换挡，之后的摘抄也从这一档起步；
- **单张卡**：复习计划面板行右键、复习界面点卡上徽标，菜单里的「回访频率」只改这一张；
- **「每 N 天」日程卡不受管**：那是你自己定的间隔；今日阅读的分片推送也不走这条曲线。接管没开也能先给书设档——算提前预置，重新开启后建卡按它起步。

（图：书卡右键 →「回访频率」子菜单：低 / 中 / 高三档，勾选为当前档（图为默认的中档））

## 分片上读与写

分片就是一个普通文档，长这样：

- 标题前带序号（[00001]、[00002]…），书卡点开的是断点那一片；
- 每段原文末尾有 \\\* 链接，点击跳回原书对应位置；
- 内容随便改：删掉重写、加段落、制卡都行，「重插」可随时把原文恢复原样；
- 片内原文与你手写的笔记同为默认色、不做区分（旧版「自己写的笔记会自动变色」已退役——想让笔记显色，见「数据存放与 CSS 自定义」的两段 CSS）。

（图：一篇分片：序号标题、正文与手写笔记）

**翻片**：浮条 ➡「下片删」读完即删开下一片；⬅「回看」跳上一片不删除；快捷键 Ctrl+← / Ctrl+→。

**从原书任意位置开始读**：打开原书文档，浏览到目标位置，右键菜单「插件 → 跳到分片或回到原文」（Shift+Alt+W），直接跳到对应分片。

**小贴士**
- 分片删除后，它本身的文档闪卡也会删掉（不影响文档内的其他闪卡）；
- 删掉的分片如果之后读到，会重新创建；
- 分片的文档标题可以改，但备注别改，插件依赖备注定位。

## 重插与断句：五档怎么选

分片切得不合心意，不用删书重来。平铺区 **重插**按钮先清空本片，再按你选的断句方式重新插入原文。**两段式操作**：选断句档位 → 确认清空重插（将清空本片全部旧内容——包括你手写的笔记，不可撤销）→ 重插完成。万一中途失败，片内已清空，再点一次重插即可恢复。

（图：重插的两段式确认：清空不可撤销，想清楚再点）

五档菜单：

| 档位 | 效果 | 免费 / Pro |
|-|-|-|
| 按书的断句设置 | 沿用加书弹窗里选的断句方式 | 免费 |
| 不断句 | 整块原文照插，不拆句 | 免费 |
| 断句为段落块 | 按句拆成一个个段落块 | Pro |
| 断句为任务块 | 按句拆成任务清单块 | Pro |
| 断句为无序表 | 按句拆成无序列表块 | Pro |

未激活时，三个 Pro 档带小锁标可见，点击即出解锁引导；「按书设置」和「不断句」两档随时可用。书级默认断句在**加书弹窗的切分设置**里选（一组点选档位），「按书的断句设置」复用的就是它。

（图：五档断句菜单：前两档免费，段落 / 任务 / 列表三档为 Pro（锁标可见））

**英文断句**：中文按标点自然断句；英文按「句点 + 空格」断句，并带缩写保护——Dr.、U.S.、p.m. 这类不会被误切，行首的列表标记也不会当成句子。

## 知识地图：让 AI 替你画关系图

读一本书读到人物关系 / 概念脉络理不清的时候，可以让 AI 替你画一张**知识地图**：节点是人物、概念、事件、地点、主题，连线是它们的关系，每个节点还带着**证据锚**——点开能跳回原文出处。

- **AI 建图**：连接 AI 客户端（ZCode / Trae 等，配置见「AI 接入（MCP）」篇）后对它说「给这本书建一张知识地图」——AI 读完书的分片素材，产出节点与关系，渐进负责对账落盘（同一实体自动合并、引用悬空自动剔除，账目在回执里全量可见）；
- **两种入口看图**：书卡右键**知识地图**，或目录浮层顶栏的切换按钮（目录答顺序、地图答关系）。全景视图自动分层（枢纽节点居中、边缘收拢成簇），点节点钻取局部，再点返回全景；
- **自己动手**：图上直接拖动布局，**保存视图**留下一张自己的切法（同一本书可以存多张视角不同的图）；视图攒多了，让 AI 用 map_tidy 归并整理；
- **导出图片**：右上角**导出图片**把当前图存成 PNG——配合思源的**图片遮挡闪卡**把导出图做成自测题，是加深记忆的组合拳：AI 画省力，深度记忆配合遮挡自测。

大书可以按卷分批建（AI 一次吃一卷，逐步拼全），节点池随书归档同步。

写作书打开同款地图，看到的是**结构树**：绿＝已定稿、主题色＝有素材、橙＝缺口、灰＝容器，每章进度一眼看全——详见「渐进写作」篇。

（图：知识地图：全景分层与节点卡（进度点条 + 摘要），连线带关系标签，右下保存视图 / 导出图片）
