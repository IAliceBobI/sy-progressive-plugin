这一篇讲**渐进写作**：你的素材排队等你写——大纲建槽、素材进槽、写完定稿、汇编成稿。

先看视频感受完整流程，下面分节展开细节。

渐进阅读的姊妹形态：阅读是「别人写好的内容排队给你读」，写作是「你的素材排队等你写」。同一套调度体系，两个工作相位。

- **写作书**：一本挂在笔记本里的普通文档，只当骨架用——真正的内容在它的**槽**里。
- **槽（分片）**：写作书下的子文档，一个槽 = 稿子的一节。建书时粘贴大纲一行一槽，之后随手拆、随手定稿；槽下还能再建子槽（多级章节），章节顺序永远跟着思源文件树走。
- **素材**：进槽的普通块副本（直送自原文、或从摘抄池转入），整条装在一个超级块「胶囊」里。素材是静态文本（块引用已转实），胶囊角上有血缘徽标，点一下跳回出处。
- **定稿**：一个槽写完了就定稿——调度不再轮到它，但随时可解除。全槽定稿 = 这本书退役。
- **汇编成稿**：把全部槽按顺序合并成一篇独立文档（Pro 功能）。

一句话串起来：**大纲建槽 → 素材进槽 → 在槽里写作 → 写完定稿 → 汇编成稿。**

# 建一本写作书

舰队总览底部或管理书目顶栏的 ✍ 按钮新建。三样东西：

1. **书名**；
2. **存放笔记本**（默认就近，建完可随意拖动）；
3. **大纲**（可选）：粘贴多行文本，一行一个槽。自带序号（`1.`、`一、`、`(2)`）会自动剥掉，不用手动清理。

不粘大纲也行——建出来是**纯收集书**：先不建槽，素材照常往里摘（进 `digest-书名` 夹的素材池），之后随时建槽、拆分。

写作书与普通渐进书在同一滚筒里混排，轮到它时分派是**素材优先**：素材池里有没读过的素材，先推**最老的一篇**（推过即标记完成，计入写作火苗的「今日已写」，不占阅读额度）；池清空了，才打开你**上次写到的槽**（全部定稿则顺延到第一个未定稿槽）。舰队进度显示 ✍ 已定稿/总槽数。

# 素材进槽

五条路。除直送外，拉式 / 推式 / 批量三条都是「摘抄本体照常进池 + 转实副本进槽」，不会产生两套摘抄体系：

- **直送（在原文上送，最省事）：任何文档里选中内容，浮条「直接入槽」→ 选书选槽，转实进槽——不进摘抄池、不建摘抄本体**，点徽标跳回原文出处；
- **拉式（在槽里挑）**：打开一个槽，浮条「插入素材」→ 按源书分组的选择器里挑一条，整条转实插到本槽尾部；
- **推式（在摘抄上送）**：摘抄浮条「入槽」→ 两级菜单选书选槽，同样转实入槽尾；
- **批量（池管理，攒一波再分）**：写作书里浮条 **📋 本书素材** → 浮层底部 **管理素材池**，打开素材池大界面：勾选多篇 → **复制入槽 / 移动入槽** → 两级菜单选书选槽。复制=原文档保留（素材多处变形）；移动=源素材文档删除、内容整体搬进槽（先弹确认）。单篇失败不中断，完成后汇总提示；
- **宽松入池（拖进即素材）**：把摘抄文档直接拖进素材池文件夹（文档树拖动），或在池夹里右键新建手写——自动获得素材身份，翻素材、消化调度立刻可见。普通文档和手写笔记都以这种方式入池；摘抄文档本身就是素材，在素材池面板按原书分组能找到它，与存放在哪个文件夹无关。

**原生操作自动记账**：不想走插件按钮也可以——`⌘X⌘V` 剪贴、拖块进槽，都会自动补上素材血缘，徽标与反查随之可用，零额外操作。

**素材池管理与消化**：素材的日常管理都在浮条与池界面——

- 写作书系文档的浮条平铺区有一段「**写作管理**」簇：**本书素材**（打开本书素材清单）、**翻素材**（槽内按池序逐条跳读素材）、**管理素材池**（打开池管理大界面）、**本书槽**；
- **池管理大界面**：搜索框 + 按原书分组的全量清单，勾选多篇后可 **复制入槽 / 移动入槽**（送往指定槽）、**转出为摘抄**（退回普通摘抄身份）、**删除**，也可一键 **全选**——删除、移动都带确认弹窗，手滑有挽回余地；
- **标记已消化**（可逆）：消化过的素材在清单里弱化沉底、不再重复推送；反悔点「取消消化标记」随时剥掉；
- 素材文档上的浮条是素材专属形态：**收集素材 / 上一条素材 / 下一条素材 / 回出处 / 素材汇总**——按行为换了名的摘抄浮条（详见「界面与个性化」篇）。

**素材与复习卡**：新建素材自带一张复习卡（有意设计——消化素材即复习），直送、转入、拖入/池内新建三条建卡点都带卡；存量素材不追溯补卡。不想让素材进复习曲线，可在 设置 → 制卡 →「阅读曲线接管（实验）」里关掉「素材」推送。

**手写内容保护**：AI 做结构整理时，槽内手写内容默认视为原创、原样不动；盘点中素材与手写分开计数，各自可见。

进槽的素材装在超级块「胶囊」里（一素材一胶囊，纵向排列保持阅读序），胶囊左上角有徽标，点击跳回出处（直送跳原文、摘抄转实跳摘抄）。素材就是普通块——直接在槽里改写、删减、重排（拖拽），想拆散胶囊随时用思源原生的「取消超级块」即可。选槽的菜单（直送 / 拉式 / 推式 / 批量四处共用）按书的章节层级树形展示，子槽缩进可见，槽多也好找。

**变形汇总**：同一个素材进过哪些槽，回头在素材这边就能看到——被入槽的内容块左缘有一条青色竖条，文档标题旁有「已入 N 槽」徽标；点竖条或徽标弹出槽名列表，点槽名直接跳到那个槽里的素材胶囊。在原文档上直送的内容同样生效。

# 槽管理

浮条上的写作书专属按钮（只在该书槽文档里出现）：

- **拆为新片**：选中若干块 → 拆 → 输入新槽名 → 这些块整体搬进一个新槽，排在当前槽之后，其余槽原样不动。大纲写细了想拆开写、写着写着想分章，都靠它；
- **定稿 / 解除定稿**：标记本槽已完成（调度跳过）。图标会记住当前状态，点一下切换，随时可逆；
- **汇编成稿（Pro）**：全书合并，见下节；
- **上一槽 / 下一槽**：槽间导航，按章节顺序跳到上 / 下一个槽（到头了会提示「已是第一个 / 最后一个槽」）。导航跳转不计数——写作火苗的「今日已写」算的是消化了多少素材，翻槽看看不算，在槽里消化素材才算；
- **本书槽**：弹出本书的全槽列表（按章节层级缩进展示，已定稿的槽带标记、当前槽高亮），点哪条直达哪条——槽多的时候不用一槽一槽翻；
- **换书**：换到下一本写作书（只在你的写作书之间环形轮转，顺序与火苗同源），只此一本时提示「没有其他写作书」。

块级搬移用浮条平铺区的「移上一片 / 移下一片」（⌃⌥U / ⌃⌥I）：把选中的块搬到相邻槽。已定稿的槽不能移入也不能移出——先解除定稿再动。

**新建空槽**（先建槽后放素材）：管理书目页写作书卡展开「分片设置」→ **新建槽** → 输入槽名，空槽追加在书尾（现有槽之后），建好即可从素材池往里送。纯收集书攒了一波素材想开工、写到中途想加新章，都走这里。

**文件树即章节顺序**：槽的顺序就是思源文件树里子文档的顺序——在文件树里拖动子文档，章节顺序跟着变；直接在文件树里给写作书新建子文档，它立刻就是一个新槽，子文档下再建子文档就是子槽（多级章节），无需任何设置。

# 结构树：一眼看到写到哪了

写作书也能打开**知识地图**（入口与阅读书相同：书卡右键「知识地图」，或目录浮层顶栏的切换按钮），打开的是这本书的**结构树**：节点就是槽，层级就是章节层级，整本书写到哪了一眼看全。

- **四色看进度**：**绿**＝已定稿；**主题色**＝有素材；**橙**＝缺口（等着填的空槽，虚线高亮）；**灰**＝有子章节的容器。每章的素材篇数和子章节数直接标在节点上，不用挨个点开数；
- **点节点直达**：点任何节点直接打开那个槽，看完缺口直奔现场；
- **导出图片**：右上角一键导出 PNG。

# 让 AI 帮你搭结构（需连接 AI）

把 AI 助手接进思源后（见「AI 接入（MCP）」篇），结构活可以交给 AI 打下手：

- **盘点与排结构**：对它说「帮我把《XXX》这本写作书的结构理一理」——AI 先盘点：素材散落在哪、槽树现在什么样、哪里有缺口；再给出骨架建议，**预演**每一步动作给你过目，你点头才真正落盘：建新槽、把散落的素材归位进对应章节；
- **放心交给它**：落盘是增量式的——**不删任何内容、不重排你已有的槽、不改任何名字**；你亲手写过的正文它一概不碰。放错了位置，在文件树里拖回来就行；
- **拆范文骨架**：把一篇好文章丢给它——「拆一下这篇的叙事骨架」——AI 拆出标题层级和各段摘录，做你搭自己稿子的参考。

（图：AI 盘点的现场：素材散落在书根，末级槽都是待补的缺口）

## AI 成文整理：让 AI 读槽写稿

同样是 AI 助手（MCP）的活：对它说「把《XXX》第三章的素材改写成初稿」——AI 读取槽内素材（structure_read），按你的要求自由改写整理，成稿落在书下的「成稿-书名-时间」文档里，**支持多稿并存**（换个体裁再写一稿，互不覆盖），也能指定在某一稿的基础上**往稿续写**。你手写的内容默认视为原创、AI 不动。

# 汇编成稿（Pro）

全部槽按顺序合并成一篇独立文档：每槽内容的块依序拼合，素材血缘徽标随块带入（成稿里也能跳回原摘抄）。重复汇编 = 幂等重新生成，以最后一次为准。

入口：写作书槽内浮条「汇编成稿」按钮，或管理书目页写作书行的「汇编成稿」按钮。未激活 Pro 时入口不隐藏，点击给出引导。

日常流（建书、调度、入槽、拆分、定稿、移片）全部免费；汇编成稿与未来 AI 改写层属于 Pro（￥72 买断，与渐进阅读 Pro 同一授权）。

## 仿写联动（需装「仿写练习」插件）

读完一片想动笔？渐进学习与「仿写练习」插件深度联动：把书或分片送进仿写，在原文上打字即批注、抽取成练习文档、合上原文凭记忆写再逐字对比。按你所在的位置，有三个入口就近取用。

- **书态：设为仿写原文**——浮条平铺区 🗺 **路线指引**浮层的底部有「仿写联动」区，点 **设为仿写原文**，整本书进入仿写模式，之后在原文上打字就是批注。已在仿写模式中时按钮变为 **删除仿写模式**（会先弹确认：删除将移除批注与已生成的抽取文档）。
- **片态：仿写本片**——分片浮条平铺区的 **仿写本片**按钮，一键把当前片整篇做成**永久副本**送进仿写并直达练习界面。副本不随删片、重插丢失，你在副本上随便写，原文毫发无伤。
- **摘抄态：送进仿写**——摘抄文档首行的「送仿写」按钮，把这篇摘抄变成仿写素材（印记与回原文能力都保留，详见本章「摘抄：✂ 子排与去向」一节）。
