这一篇讲**渐进写作**：你的素材排队等你写——大纲建槽、素材进槽、写完定稿、汇编成稿。

渐进阅读的姊妹形态：阅读是「别人写好的内容排队给你读」，写作是「你的素材排队等你写」。同一套调度体系，两个工作相位。

- **写作书**：一本挂在笔记本里的普通文档，只当骨架用——真正的内容在它的**槽**里。
- **槽（分片）**：写作书下的子文档，一个槽 = 稿子的一节。建书时粘贴大纲一行一槽，之后随手拆、随手定稿。
- **素材**：进槽的普通块副本（直送自原文、或从摘抄池转入），整条装在一个超级块「胶囊」里。素材是静态文本（块引用已转实），胶囊角上有血缘徽标，点一下跳回出处。
- **定稿**：一个槽写完了就定稿——调度不再轮到它，但随时可解除。全槽定稿 = 这本书退役。
- **汇编成稿**：把全部槽按顺序合并成一篇独立文档（Pro 功能）。

一句话串起来：**大纲建槽 → 素材进槽 → 在槽里写作 → 写完定稿 → 汇编成稿。**

# 建一本写作书

舰队总览底部或管理书目顶栏的 ✍ 按钮新建。三样东西：

1. **书名**；
2. **存放笔记本**（默认就近，建完可随意拖动）；
3. **大纲**（可选）：粘贴多行文本，一行一个槽。自带序号（`1.`、`一、`、`(2)`）会自动剥掉，不用手动清理。

不粘大纲也行——建出来是**纯收集书**：先不建槽，素材照常往里摘（进 `digest-书名` 夹的素材池），之后随时建槽、拆分。

写作书与普通渐进书在同一滚筒里混排，轮到它时分派是**素材优先**：素材池里有没读过的素材，先推**最老的一篇**（推过即标记完成，今日阅读计数 +1，与读分片同权）；池清空了，才打开你**上次写到的槽**（全部定稿则顺延到第一个未定稿槽）。舰队进度显示 ✍ 已定稿/总槽数。

# 素材进槽

四条路。前三条是「摘抄本体照常进池 + 转实副本进槽」，不会产生两套摘抄体系：

- **直送（在原文上送，最省事）：任何文档里选中内容，浮条「直接入槽」→ 选书选槽，转实进槽——不进摘抄池、不建摘抄本体**。素材是纯普通文本（无复习卡），点徽标跳回原文出处。适合「这段就是给稿子用的，不需要复习」的场景；
- **拉式（在槽里挑）**：打开一个槽，浮条「插入素材」→ 按源书分组的选择器里挑一条，整条转实插到本槽尾部；
- **推式（在摘抄上送）**：摘抄浮条「入槽」→ 两级菜单选书选槽，同样转实入槽尾；
- **批量（池管理，攒一波再分）**：写作书里浮条 **📋 本书摘抄** → 浮层底部 **管理素材池**，打开素材池大界面：勾选多篇 → **复制入槽 / 移动入槽** → 两级菜单选书选槽。复制=原文档保留（素材多处变形）；移动=源素材文档删除、内容整体搬进槽（先弹确认）。单篇失败不中断，完成后汇总提示。

进槽的素材装在超级块「胶囊」里（一素材一胶囊，纵向排列保持阅读序），胶囊左上角有徽标，点击跳回出处（直送跳原文、摘抄转实跳摘抄）。素材就是普通块——直接在槽里改写、删减、重排（拖拽），想拆散胶囊随时用思源原生的「取消超级块」即可。

**变形汇总**：同一个素材进过哪些槽，回头在素材这边就能看到——被入槽的内容块左缘有一条青色竖条，文档标题旁有「已入 N 槽」徽标；点竖条或徽标弹出槽名列表，点槽名直接跳到那个槽里的素材胶囊。在原文档上直送的内容同样生效。

# 槽管理

浮条上三个写作书专属按钮（只在该书槽文档里出现）：

- **拆为新片**：选中若干块 → 拆 → 输入新槽名 → 这些块整体搬进一个新槽，插在当前槽之后，后面的槽自动顺延编号。大纲写细了想拆开写、写着写着想分章，都靠它；
- **定稿 / 解除定稿**：标记本槽已完成（调度跳过）。图标会记住当前状态，点一下切换，随时可逆；
- **汇编成稿（Pro）**：全书合并，见下节。

块级搬移用浮条平铺区的「移上一片 / 移下一片」（⌃⌥U / ⌃⌥I）：把选中的块搬到相邻槽。已定稿的槽不能移入也不能移出——先解除定稿再动。

**新建空槽**（先建槽后放素材）：管理书目页写作书卡展开「分片设置」→ **新建槽** → 输入槽名，空槽追加在书尾（现有槽之后），建好即可从素材池往里送。纯收集书攒了一波素材想开工、写到中途想加新章，都走这里。

# 汇编成稿（Pro）

全部槽按顺序合并成一篇独立文档：每槽内容的块依序拼合，素材血缘徽标随块带入（成稿里也能跳回原摘抄）。重复汇编 = 幂等重新生成，以最后一次为准。

入口：写作书槽内浮条「汇编成稿」按钮，或管理书目页写作书行的「汇编成稿」按钮。未激活 Pro 时入口不隐藏，点击给出引导。

日常流（建书、调度、入槽、拆分、定稿、移片）全部免费；汇编成稿与未来 AI 改写层属于 Pro（￥72 买断，与渐进阅读 Pro 同一授权）。

## 仿写联动（需装「仿写练习」插件）

读完一片想动笔？渐进学习与「仿写练习」插件深度联动：把书或分片送进仿写，在原文上打字即批注、抽取成练习文档、合上原文凭记忆写再逐字对比。按你所在的位置，有三个入口就近取用。

- **书态：设为仿写原文**——浮条平铺区 🗺 **路线指引**浮层的底部有「仿写联动」区，点 **设为仿写原文**，整本书进入仿写模式，之后在原文上打字就是批注。已在仿写模式中时按钮变为 **删除仿写模式**（会先弹确认：删除将移除批注与已生成的抽取文档）。
- **片态：仿写本片**——分片浮条平铺区的 **仿写本片**按钮，一键把当前片整篇做成**永久副本**送进仿写并直达练习界面。副本不随删片、重插丢失，你在副本上随便写，原文毫发无伤。
- **摘抄态：送进仿写**——摘抄文档首行的「送仿写」按钮，把这篇摘抄变成仿写素材（印记与回原文能力都保留，详见本章「摘抄：✂ 子排与去向」一节）。
