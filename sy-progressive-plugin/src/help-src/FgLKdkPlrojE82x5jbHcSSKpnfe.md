## 摘抄：✂ 子排与去向

点浮条 ✂（书态 / 片态公共组、自由态主钮）展开**摘抄子排**——八个去向按钮，把「选中或光标所在的块」摘成一份**副本文档**：改摘抄不影响原文，原文数据保持干净。目标怎么认（选中 / 光标 / 拖蓝）见「浮条工作台 · 先选后点」。

| 去向 | 干什么 | 产物 |
|-|-|-|
| 留档（默认） | 纯摘抄留存 | prog-data 的 digest-书名 文件夹里一条摘抄文档 |
| 思考 | 摘下并标为问题 | 标题带 ❓ 前缀，自动进 3 天起的重访曲线（见本章末节） |
| 背诵 | 摘下并加入闪卡 | 摘抄文档 + 文档级闪卡，进附属卡复习 |
| 单词 | 收进本书单词本 | words-书名 文档里一个词条（须先选中文字，见「生词」一节） |
| 生词 AI（Pro） | 收词 + AI 双语释义与例句 | 词条 + AI 释义块；未激活时收录照常、AI 跳过并给解锁引导 |
| 仿写 | 送进仿写练习 | 片态=把本片整篇副本送进仿写开练；其他态=送当前文档；需装「仿写练习」插件（见「仿写联动」章） |
| 重访调度 | 给选中块挂一个温和的重访闹钟 | 不产生摘抄，只打调度标记（见本章末节） |
| 整篇摘抄（片态） | 整片 / 整文复制成副本 | 标题带 [整] 前缀的副本文档，适合「先全收、再挑拣」 |

几个顺手的细节：

- **快路径**：选中后直接按 **Shift+Alt+Z 执行摘抄**（等价「留档」）；**Shift+Alt+X 摘抄并断句**——按标点把内容拆成一句一行，长段落摘下来更好读；
- **Alt+Z** 在书 / 分片 / 摘抄文档里展开摘抄子排，在普通文档里则让浮条「自由态上岗」；右键菜单与块图标菜单里的「渐进阅读摘抄模式」是同一个入口；
- 任意文档右键还有「**整篇摘抄**」，把整篇收进札记匣或摘抄文件夹；
- **摘抄可以再摘抄**：在摘抄文档里继续 ✂，产物落札记匣，浮条与「回原书」能力照常；
- 摘抄标题 = [序号] + 内容前十字（思考带 ❓、整篇带 [整]、仿写副本带「仿写」前缀），多级摘抄不会生成多级文件夹，都在同一个 digest 文件夹里；
- 只读模式下同样可以摘抄。

**旧版用户看这里**
- 旧 Alt+Z 菜单里的「打开上一个 / 下一个摘抄」「清理已完成的摘抄」已随菜单改版移除——找摘抄用「本书摘抄清单」浮层或摘抄态的路线图浮层，清理直接删文档即可；
- 摘抄痕迹不再写原文（详见下一节），旧版留在正文里的背景色、加号链接不影响使用，想清掉手动删除即可。

## 摘抄痕迹与旧版迁移

摘抄后，原文里对应的块左缘会出现一条**竖条印记**——这就是「已摘过」的痕迹：

- **点击竖条**跳到对应的摘抄文档；同一块摘过多次会弹列表挑选；
- 反方向，摘抄文档里点浮条「回原书」定位回原文块——书、片、摘抄之间的路永远通；
- 痕迹是**渲染态**标记：只改显示、不写正文，刷新页面即重新打点，导出 .sy 与同步数据里都不会出现它；
- 想要更显眼的提示？设置 → 摘抄与制卡 →「**已摘抄块显示背景色**」（默认关闭）：已摘块整块铺淡背景，与竖条叠加显示，同样只改显示不写正文。

（图：书态原文：已摘块左缘的竖条印记，点击跳对应摘抄）

**旧版迁移（v3.0.0 起行为变化）**
- **摘抄 / 制卡不再向原文写入任何标记**：痕迹改为上面的渲染态竖条 + 可选背景，原文数据保持干净。旧版写入正文的背景色不受新开关控制，需要手动清除；
- 「制卡摘抄在原文处做标记」开关已移除；
- 摘抄「完成标记」（🔨）退役：写入口已移除，存量标记在路线图与清单里弱化显示（数据不丢）；想终结一本书的推送请用浮条「归档」；
- 片内双色退役：分片原文与你手写的笔记同为默认色（见「分片上读与写」）。

## 札记匣与本书摘抄清单

所有摘抄产物集中在 prog-data 文件夹（可改名、可移动，插件按 ID 认回）：

| 产物 | 落点 | 说明 |
|-|-|-|
| 书内摘抄 | digest-书名 / | 每条摘抄一个文档，附属卡与摘抄汇总都以这个文件夹为单位 |
| 非书文本的摘抄 | 札记匣 / | 普通文档摘抄、摘抄再摘抄都进这里，用法与书摘抄一致 |
| 单词 | words-书名 | 长期生词资产（见「生词」一节） |
| 阅读日志 | 阅读日志 | 每日阅读记账，舰队热力图的数据源 |

**找一条摘抄**，不用翻文件夹：

- 书态 / 片态浮条平铺区的「**本书摘抄**」按钮打开清单浮层：顶部是「当前块所在分片」（点击跳片），下面按时间倒序列出本书最近 30 条摘抄，点击直达；
- 摘抄超过 30 条时，浮层底部出现「**查看全部 N 条**」，升级成大界面——搜索框 + 全量清单（每条带创建日期），筛选、定位都方便；
- 摘抄态浮条的「**路线图**」按钮换一个视角：全书摘抄树（在摘抄上再摘抄会挂成子节点）+ 本书批注分组，点击任意节点跳转；
- 书态 / 摘抄态的「**摘抄汇总**」按钮直接打开 digest-书名 文件夹本身，交给思源文档树管理。

## 笔记与整理：提取 · 合并 · 收集 · 移动

片是你的草稿纸，四条整理通道把它变成成品（都在浮条平铺区的「提取整理」与「移动」组，也可右键分片或用快捷键）：

| 功能 | 快捷键 | 作用 |
|-|-|-|
| 提取笔记（本片） | Ctrl+F5（Pro） | 把本片手写笔记提取到 keys- 开头的笔记文档 |
| 提取所有分片的笔记 | Ctrl+F4（Pro） | 把所有分片的笔记一次归总到 keys- 文档 |
| 提取笔记到底部 | Shift+Alt+R（Pro） | 把本片笔记聚合成一个块，放到片文档底部 |
| 去除 / 恢复笔记颜色 | Alt+Ctrl+F5 / F6（Pro） | 去掉或恢复笔记的颜色标记，内容不动 |
| 合并所有分片为新文件 | Alt+Ctrl+F7（Pro） | 读完全书，把所有分片（含你的修改）合成一本新书，可再加书开始新一轮 |
| 收集 | Shift+Alt+O（Pro） | 把选中的块复制进本书 summary- 汇总文档，适合前后对照（旧称「搜集」） |
| 移动到上一 / 下一分片 | Ctrl+Alt+U / Ctrl+Alt+I | 把选中的块搬到相邻分片，重新组织内容（免费，挪片属核心阅读流） |

（图：平铺区高级组：制卡 / 收集 / 移动 / 提取整理）

**旧版用户看这里**
- 「收集到 dailynote」分支已移除：收集固定收进本书的 summary 汇总文档；
- keys → compare「对比原文」工作流已退役：keys- 精读文档仍是可读可写的笔记容器，「对照原文练笔」由仿写练习插件接棒；
- 提取 / 合并 / 收集 / 去色属 Pro 的「收集与写作对比族」，未激活时按钮灰显并带解锁引导；移动分片块保持免费。
