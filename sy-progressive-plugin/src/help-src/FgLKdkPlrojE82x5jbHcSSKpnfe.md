## 摘抄：✂ 子排与去向

点浮条 ✂（书态 / 片态公共组、自由态主钮）展开**摘抄子排**——按文档形态 8~12 个去向按钮（图为摘抄态），把「选中或光标所在的块」摘成一份**副本文档**：改摘抄不影响原文，原文数据保持干净。目标怎么认（选中 / 光标 / 拖蓝）见「浮条工作台 · 先选后点」。

| 去向 | 干什么 | 产物 |
|-|-|-|
| 留档（默认） | 纯摘抄留存 | prog-data 的 digest-书名 文件夹里一条摘抄文档 |
| 思考 | 摘下并标为问题 | 标题带 ❓ 前缀，自动进 3 天起的重访曲线（见本章末节） |
| 背诵 | 摘下并加入闪卡 | 摘抄文档 + 文档级闪卡，进附属卡复习 |
| 复访 | 摘下并加入滚动复访 | 摘抄文档按回访节奏到期重现，书卡 ✒ 徽章提醒 |
| 单词 | 收进本书单词本 | words-书名 文档里一个词条（须先选中文字，见「生词」一节） |
| 生词 AI（Pro） | 收词 + AI 双语释义与例句 | 词条 + AI 释义块；未激活时收录照常、AI 跳过并给解锁引导 |
| 仿写 | 送进仿写练习 | 送当前文档整篇开练（片态走平铺区低频段「仿写本片」钮，子排无此钮）；需装「仿写练习」插件（见「仿写联动」章） |
| 重访调度 | 给选中块挂一个温和的重访闹钟 | 不产生摘抄，只打调度标记（见本章末节） |
| 整篇摘抄（片态） | 整片 / 整文复制成副本 | 标题带 [整] 前缀的副本文档，适合「先全收、再挑拣」 |

**落点变体**：书态子排里「留档」旁还有**摘抄挂书侧 / 摘抄归总夹**两钮（素材语境下挂书侧=本书素材池），逐次覆盖「摘抄落点」设置——这一次摘抄临时落到书下或总夹，不改全局默认档。「摘抄落点」共四档（设置 → 摘抄）：**集中归档**（默认。书/非书统一进 prog-data/摘抄/digest-来源名——书是 digest-书名、普通文档是 digest-源文档名；在摘抄里再摘也归回出生原书/来源文档的 digest-，一本书的摘抄聚在一处（v3.25.0），集中统一管理）、**源文档下方**（挂在来源书/文档之下，老版行为）、**Daily card 目录**（落进发起文档所在笔记本的 daily card/年/月目录）、**当前文档子文档**（直接挂在发起文档之下，不建夹，SM 式知识树）。子文档档**只在发起文档是摘抄时生效**（v3.24.0）——在片或普通文档里发起时自动按「源文档下方」口径落：片会解析回原书、落原书的 digest-，跟这本书的摘抄聚在一起，不再把片当一本新书。曾在 v3.24.0~v3.25.0 选过**当前文档同级**档的，升级后自动改为「源文档下方」（该档已移除，摘抄统一归原书 digest-）。

几个顺手的细节：

- **快路径**：选中后直接按 **Shift+Alt+Z 执行摘抄**（等价「留档」）；**Shift+Alt+X 摘抄并断句**——按标点把内容拆成一句一行，长段落摘下来更好读。断句不再丢行内样式：跨句的加粗、变色、高亮、删除线、行内代码、链接在切开后自动补全标记对，样式完整保留；
- **容器里选段只收选中段**：在列表块、引述块这类容器里选中几段再摘抄 / 背诵 / 制卡，只收实际选中的那几个块，不把整个容器捎带进去；选中内容恰好盖满整个列表项时保持整项收录；
- **Alt+Z** 在书 / 分片 / 摘抄文档里展开摘抄子排，在普通文档里则让浮条「自由态上岗」；右键菜单与块图标菜单里的「渐进阅读摘抄模式」是同一个入口；
- 任意文档右键还有「**整篇摘抄**」，把整篇收进 digest 文件夹（落点随「摘抄落点」设置）；
- **摘抄可以再摘抄**：在摘抄文档里继续 ✂，产物归**出生原书的 digest-**——不管从书、片还是摘抄里发起、隔几级摘，一本书的摘抄都聚在一处（v3.25.0；出生原书已删时落到这篇摘抄自己的 digest- 兜底），浮条与「回原书」能力照常；「当前文档子文档」档照常挂摘抄之下（树状玩法不受影响）；复习界面的摘抄卡上也能再摘——尾卡动作区的**再摘抄**钮可用（其余动作在复习中收起防搅局），划选卡上内容直接摘走，不切文档；
- 摘抄标题 = [序号] + 内容前十字（思考带 ❓、整篇带 [整]、仿写副本带「仿写」前缀），多级摘抄不会生成多级文件夹，都在同一个 digest 文件夹里；
- 只读模式下同样可以摘抄。

**旧版用户看这里**
- 旧 Alt+Z 菜单里的「打开上一个 / 下一个摘抄」「清理已完成的摘抄」已随菜单改版移除——找摘抄用「本书摘抄清单」浮层或摘抄态的路线图浮层，清理直接删文档即可；
- 摘抄痕迹不再写原文（详见下一节），旧版留在正文里的背景色、加号链接不影响使用，想清掉手动删除即可。

## 摘抄痕迹与旧版迁移

摘抄后，原文里对应的块左缘会出现一条**竖条印记**——这就是「已摘过」的痕迹：

- **点击竖条**跳到对应的摘抄文档；同一块摘过多次会弹列表挑选；
- 反方向，摘抄文档里点浮条「回原书」定位回原文块——书、片、摘抄之间的路永远通；
- 痕迹是**渲染态**标记：只改显示、不写正文，刷新页面即重新打点，导出 .sy 与同步数据里都不会出现它；
- 想要更显眼的提示？设置 → 摘抄与制卡 →「**已摘抄块显示背景色**」（默认关闭）：已摘块整块铺淡背景，与竖条叠加显示，同样只改显示不写正文。

（图：书态原文：已摘块左缘的竖条印记，点击跳对应摘抄）

**摘抄文档自己也有身份牌**：摘抄文档标题旁有**类型胶囊**（复访 / 思考 / 心得 / 背诵 / 仿写 / 留档六态，复访到期会变红，点复访胶囊可直接调节奏）；「本书摘抄清单」里每条前有对应的**单字小标**（访 / ? / ✓ / 背 / 仿 / 档），扫一眼就知道这条摘抄进了哪条线。

**旧版迁移（v3.0.0 起行为变化）**
- **摘抄 / 制卡不再向原文写入任何标记**：痕迹改为上面的渲染态竖条 + 可选背景，原文数据保持干净。旧版写入正文的背景色不受新开关控制，需要手动清除；
- 「制卡摘抄在原文处做标记」开关已移除；
- 摘抄「完成标记」（🔨）退役：写入口已移除，存量标记在路线图与清单里弱化显示（数据不丢）；想终结一本书的推送请用浮条「归档」；
- 片内双色退役：分片原文与你手写的笔记同为默认色（见「分片上读与写」）。

## 摘抄总夹与本书摘抄清单

所有摘抄产物集中在 prog-data 文件夹（可改名、可移动，插件按 ID 认回）：

| 产物 | 落点 | 说明 |
|-|-|-|
| 书内摘抄 | 摘抄 / digest-书名 / | 每条摘抄一个文档，附属卡与摘抄汇总都以这个文件夹为单位 |
| 非书文本的摘抄 | 摘抄 / digest-源文档名 / | 普通文档摘抄与书并排进总夹（以来源为名）；摘抄里再摘也归回来源文档的 digest-（v3.25.0），用法与书摘抄一致 |
| 单词 | words-书名 | 长期生词资产（见「生词」一节） |
| 阅读日志 | 阅读日志 | 每日阅读记账，舰队热力图的数据源 |

**老数据看这里**：历史版本的非书摘抄落在「札记匣」文件夹（匣内按源文档 digest-源文档名 分夹归集）；升级后存量原地不动，清单、复访与「回原书」照常可用，新摘抄统一进摘抄总夹、不再新建札记匣。

**找一条摘抄**，不用翻文件夹：

- 书态 / 片态浮条平铺区的「**本书摘抄**」按钮打开清单浮层：顶部是「当前块所在分片」（点击跳片），下面按时间倒序列出本书最近 30 条摘抄，点击直达；
- 摘抄超过 30 条时，浮层底部出现「**查看全部 N 条**」，升级成大界面——搜索框 + 全量清单（每条带创建日期），筛选、定位都方便；
- 摘抄态浮条的「**路线图**」按钮换一个视角：全书摘抄树（在摘抄上再摘抄会挂成子节点）+ 本书批注分组，点击任意节点跳转；
- 书态 / 摘抄态的「**摘抄汇总**」按钮直接打开 digest-书名 文件夹本身，交给思源文档树管理。

## 批量整理摘抄：整书一波送进素材池

摘抄攒了一书、想整批送进写作书素材池接着用？不用一篇篇手动搬（v3.22.0）：入口两处——书卡右键「**批量整理摘抄…**」，或浮条摘抄子排的「**批量整理**」钮（自由态页面没有所属书，不出此钮）。清单支持搜索、全选、逐条勾选，选好目标写作书后跑批，动作两档：

| 动作 | 干什么 |
|-|-|
| 批量复制入池 | 复制进对方素材池，本书摘抄原文留底，两边都在 |
| 批量换籍 | 摘抄文档整体移进对方素材池，本书清单随之移除（先弹确认） |

跑批逐篇显示进度，完成后给明细回执——跳过 / 失败的原因逐条列明；复制有失败篇可**只重试失败篇**（复制非幂等，整批重跑会出双份），换籍幂等、整批重跑安全。单批上限 100 篇，超出会提示分批（建议每批 50~100 篇）。收进来的素材怎么调度，见「渐进写作」篇。

## 笔记与整理：提取 · 合并 · 收集 · 移动

片是你的草稿纸，四条整理通道把它变成成品（都在浮条平铺区的「提取整理」与「移动」组，也可右键分片或用快捷键）：

| 功能 | 快捷键 | 作用 |
|-|-|-|
| 提取笔记（本片） | Ctrl+F5（Pro） | 把本片手写笔记提取到 keys- 开头的笔记文档 |
| 提取所有分片的笔记 | Ctrl+F4（Pro） | 把所有分片的笔记一次归总到 keys- 文档 |
| 提取笔记到底部 | Shift+Alt+R（Pro） | 把本片笔记聚合成一个块，放到片文档底部 |
| 去除 / 恢复笔记颜色 | Alt+Ctrl+F5 / F6（Pro） | 去掉或恢复笔记的颜色标记，内容不动 |
| 合并所有分片为新文件 | Alt+Ctrl+F7（Pro） | 读完全书，把所有分片（含你的修改）合成一本新书，可再加书开始新一轮 |
| 收集 | Shift+Alt+O（Pro） | 把选中的块复制进本书 summary- 汇总文档，适合前后对照（旧称「搜集」） |
| 移动到上一 / 下一分片 | Ctrl+Alt+U / Ctrl+Alt+I | 把选中的块搬到相邻分片，重新组织内容（免费，挪片属核心阅读流） |

（图：平铺区高级组：制卡 / 收集 / 移动 / 提取整理）

**旧版用户看这里**
- 「收集到 dailynote」分支已移除：收集固定收进本书的 summary 汇总文档；
- keys → compare「对比原文」工作流已退役：keys- 精读文档仍是可读可写的笔记容器，「对照原文练笔」由仿写练习插件接棒；
- 提取 / 合并 / 收集 / 去色属 Pro 的「收集与写作对比族」，未激活时按钮灰显并带解锁引导；移动分片块保持免费。
