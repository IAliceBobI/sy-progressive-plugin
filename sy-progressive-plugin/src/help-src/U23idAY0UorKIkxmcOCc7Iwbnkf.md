## 浮条工作台

浮条是随身工作台，随四种文档自动出场，按钮随场景变化：

| 状态 | 出场时机 | 首行主要按钮 |
|-|-|-|
| 书态 | 打开书（原文文档） | 继续读 / 附属卡 / 换书 / 摘抄汇总 / 加书 / 归档 |
| 片态 | 打开分片 | ✂ 摘抄 / 附属卡 / 换书 / 下片删 / 回看 / 打开原书 / 加书 |
| 摘抄态 | 打开摘抄文档 | 回原书 / 附属卡 / 换书 / 摘抄汇总 / 送进仿写 |
| 自由态 | 任意普通文档，点状态栏 ✂ 或按 Alt+Z「上岗」（本会话有效，✕ 即下班） | ✂ 摘抄 / 📥 加书 / 🗺 路线指引 |

结构分两层（下图片态）：**首行**是常用大钮；**平铺区**是图标 + 短标签的小格——低频按钮（目录 / 重插 / 删原文 / 删片退出 / 不再推送）和四组高级功能（制卡 / 收集 / 移动 / 提取整理）都在这里，不需要时点首行行尾的箭头钮**一键折叠**。

（图：片态浮条：首行大钮 + 平铺区（低频段与制卡/收集/移动/提取整理四组））

（图：折叠态：只留首行，点行尾箭头随时展开）

- **拖拽换位**：桌面片态下，首行按钮可拖拽排序，平铺区的按钮也能拖上首行、或拖出去放回平铺区——把最顺手的按钮摆在最顺手的位置；
- **按钮可自定义**：设置 → 浮条，28 个按钮全量勾选去留（勾 = 首行）。移动端没有拖拽，全靠设置面板；
- **三行提示**：悬停任何按钮，气泡给出「按钮名 / 一句话用法 / 快捷键（如有）」三行说明，不用背图标；
- **球与位置**：✕ 把浮条收回成球（球点一下回来），浮条可以整体拖到屏幕任意位置，位置会记住。

**✂ 摘抄子排**：点 ✂ 展开去向分诊——留档 / 思考 / 背诵 / 单词 / 生词 AI / 仿写 / 重访调度 / 整篇摘抄等，一次选定用途，之后可以改：

（图：✂ 摘抄子排：八个去向按钮，悬停任意按钮看三行用法说明（图为「留档」））

**自由态**是 v3.0.0 的新入口：阅读任何普通文档（不在书系里的）时，点状态栏 ✂ 或按 Alt+Z，浮条立场上岗——本会话内所有普通文档都有 ✂ 摘抄与 📥 加书可用，随时把好文收进渐进体系：

（图：自由态浮条：普通文档上的 ✂ 与 📥）

### 先选后点：按钮怎么认目标

一句话心智模型：**选中了用选中的，没选中用光标所在的；只有「单词」必须先选中文字；文档级按钮与选不选无关。**

| 按钮类型 | 操作目标怎么来 |
|-|-|
| 制卡四钮 | 块选中优先（点块图标 / Ctrl 点选 / Esc 转块选）→ 整块制卡；没有块选中时看光标块：有拖蓝文字做挖空卡，没有拖蓝整块制卡 |
| 摘抄 / 收集 / 移动 | 块选中 → 拖蓝覆盖的块 → 光标所在块兜底：光标放进目标块即可生效，不必选中 |
| 文档级（翻片、开书、提取、合并、归档、整篇摘抄等） | 对当前分片或书整体生效，与选不选无关 |

几个容易猜不到的细节：

- 拖蓝跨块时：制卡只取拖蓝末端所在的块，收集、移动则取拖蓝覆盖的全部块——想整块制卡，先按 Esc 转块选；
- 「多行」：有拖蓝只标记拖蓝的文字；没有拖蓝时对光标块做挖空切换，可反复点加 / 去；
- 「单词」必须先选中文字（块选中不算，要先拖蓝文字）；
- 「仿写」送的是当前整个文档，不是选中内容。

## 状态栏火苗与 ✂

状态栏左端住着两位常驻角色：

- **火苗**：常驻仪表灯，芯焰颜色 = 今日状态（绿 = 已清 / 黄 = 还有欠 / 红 = 连续两天没读），悬停可见今日读数与欠债，**点击直达滚筒下一片**；
- **✂**：自由摘抄入口——任意普通文档点它（或按 Alt+Z）唤出浮条，详见上一节的自由态。

（图：状态栏左端：火苗与 ✂）

## Dock 舰队总览

左侧 Dock 的「舰队总览」面板（面板标题写作「今日阅读」，两者同指）是驾驶舱，从上到下四块：

- **今日状态区**：已读大字（x / 档位）、欠债提示、档位胶囊（轻 1 / 常 3 / 冲 5，点击即切）；
- **书卡**：进度条、今日已读点、✒ 摘抄 / ✱ 心得 / ✧ 问题到期徽章，点击直达该书的断点分片；
- **近 14 天热力条**：每天读了多少一眼扫过；
- **管理书目**：不再推送的书、归档的书都在这里恢复或清理。

（图：左 Dock 舰队总览面板：今日状态、书卡、热力与管理书目）

异常的书会沉底并标明原因：⏸ 笔记本已关闭（灰化虚线框，开回笔记本即恢复）、⚠ 疑似失效（黄色警示框，原文被删，点击给对症处理提示）——不会再悄无声息地消失。

## 皮肤系统：三维混搭你的工作台（Pro）

浮条、舰队面板、设置面板的外观由三个维度决定——**配色 × 火苗 × 材质**。三个维度正交，任意混搭，点选即存，亮暗主题各自适配。

- **配色**（6 款）：青瓷黛蓝（免费默认）｜琉璃琥珀、松烟黛紫、绯樱落霞、苍山雾雪、墨玉轻雾（Pro）；
- **火苗**（5 款）：经典泪滴（免费）｜鹅毛笔羽焰、纸灯笼焰、双芯双焰、破浪焰（Pro）；
- **材质**（3 款）：素面（免费）｜毛玻璃、宣纸（Pro）。

（图：皮肤货架在设置面板首区「皮肤外观」：三维点选即存（图为亮色主题））

（图：同一套皮肤在暗色主题下自动适配（图为暗色主题））

**参数微调**（Pro）：在选定的配色上继续微调——色相 ±30°、亮度 ±20% 两个滑杆，调好后可自定义命名（不超过 12 个字）存成你自己的皮肤。着色作用于强调色三基色，卡片、进度、热力图、徽章全部自动重算，全局观感一致。

未激活时免费款完整可用、不降级；Pro 款带 Pro 角标可见，点击即出解锁引导。Pro 是整个皮肤系统的买断价，包含未来新增的皮肤。

## 移动端：顶栏形态

手机屏幕窄，浮条拖来拖去碍事——渐进学习在移动端不做浮球、不做拖拽，改为**固定顶栏**：钉在工具栏下方的全宽矮条，始终在你拇指够得着的地方，不遮正文。

（图：移动端片态顶栏：按钮折行排布，展开时正文自动下移让位）

与桌面端的差异：

- 浮条的全部按钮收进顶栏——主排行横向滚动（右缘渐隐提示还能滑），候选区、摘抄子排展开时折行撑高，正文自动下移让位；
- 平铺区按钮用短文字标签（移动端没有悬停提示）；
- 不习惯顶栏？设置面板「浮条」区有**移动端浮条固定顶部**开关（默认开），关掉即回到可拖拽浮条。
